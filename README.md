# CIT ポータル ＆ TOTP 統合マネージャー (PWA)

大学ポータルサイトへのログインとTOTP（二要素認証）生成を1画面で完結させるWebアプリケーション（PWA対応）です。

## 💡 解決する課題
- **「OTPアプリとブラウザを往復している間に30秒が切れて認証エラーになる」問題を根本解決！**
- 1画面の分割ビューで、TOTPコードを常時監視・ワンクリックコピーしながらポータル画面へ即座に入力できます。

---

## 🚀 主な機能

### 1. サイドバー OTP ジェネレーター
- **リアルタイムTOTP生成**: 登録したBase32シークレットキーから6桁の認証コードをリアルタイム生成（RFC 6238準拠）。
- **Web Crypto API & OTPAuth 両対応**: オフラインやPWA単体でも完全動作。
- **ワンクリックコピー**: コード部分をタップ/クリックするだけで瞬時にクリップボードへコピー。
- **アカウント管理**: 複数のアカウント登録、編集、削除、デモキーのワンクリック適用。

### 2. ⚡ 期限切れ回避ロジック（スマート待機＆自動コピー）
- **5秒未満のアラート待機モード**: 残り時間が5秒未満になると、誤って期限切れ寸前のコードを使って失敗するのを防ぐため、黄色/赤色の「⚠️ 次のコードを待機中…」画面に自動遷移します。
- **新コード瞬時自動コピー**: 30秒の新しい周期に入った瞬間に、新しい6桁コードを自動でクリップボードへ格納し、優しい通知チャイム（Web Audio API）とトーストでお知らせします。
- **たっぷり30秒**: これにより、ポータル画面側で常に30秒の猶予を持った状態で余裕をもってログイン操作を完了できます。

### 3. 埋め込みポータルビュー ＆ 並列ウィンドウ連携
- **Iframe / WebView**: 画面右側に大学ポータルのログイン画面を表示。
- **URLナビゲーション**: ポータルURLの入力、再読み込み、デフォルト復帰に対応。
- **並列ウィンドウモード（X-Frame-Options対策）**:
  - 大学の認証サーバー等でiframe埋め込みが制限（`X-Frame-Options: SAMEORIGIN` / CSP）されている場合でも、**「並列ウィンドウ」**ボタンを押すことで、右側画面にピッタリ並べて同期ウィンドウを開くことができます。
  - 左側のPWAウィンドウから自動コピーされた最新コードを、そのまま `Ctrl+V` (または `Cmd+V`) でペーストできます。

### 4. PWA (Progressive Web Apps) 対応
- `manifest.webmanifest` と `service-worker.js` を完備。
- スマホ（iOS Safari / Android Chrome）やPC（Chrome / Edge / Safari）で**「ホーム画面に追加」または「アプリとしてインストール」**することで、ネイティブアプリ感覚で利用可能。

## 🛠 起動方法

ローカルサーバーを起動してブラウザで開きます。

### Pythonを使用する場合
```bash
python3 -m http.server 3000
```
起動後、ブラウザで `http://localhost:3000` にアクセスしてください。

### Node.js (npx serve) を使用する場合
```bash
npx serve .
```

## 📁 ファイル構成
- `index.html`: アプリケーション本体（UI、TOTP生成ロジック、期限切れ回避、Tailwind CSS）
- `manifest.webmanifest`: PWA用マニフェストファイル
- `service-worker.js`: PWAオフラインキャッシュ＆サービスワーカー
- `icon.svg` / `icon-192.png` / `icon-512.png`: PWAアプリアイコン
